# Проверка наряда

Считает, сколько работы и детали из заказ-наряда автосервиса стоят на самом деле — по нормативам трудоёмкости и рыночным ценам.

**Открыть:** https://woorldmun-commits.github.io/naryad-check/

Одна страница, без сервера и без сборки. Работает офлайн после первой загрузки.

## Что внутри

- **47 операций** с нормативами в нормо-часах, коэффициентами по типу авто и примечаниями о том, когда доплата законна
- **134 города**: ставка нормо-часа своя у каждого, у 25 из них — из реальных прайсов СТО, у остальных оценка по городу-аналогу
- **57 марок и 293 модели** — китайские, немецкие, японские, корейские, американские, отечественные
- **25 позиций деталей** с ценами по площадкам и артикулами

## Как считает

Работа: `норматив в н/ч × коэффициенты авто × ставка нормо-часа города`. Деталь: розничная цена плюс рыночная наценка сервиса, до +30% — норма, свыше +70% — завышение.

Вилка широкая там, где данных мало. Если ставка нормо-часа не указана, расчёт идёт по всему диапазону города, строки помечаются «оценочно» и вердикт не поднимается до «завышения» — обвинять, опираясь на угаданный множитель, нельзя.

## Чего расчёт не делает

Не оценивает, **нужна ли была работа**. Сверяется цена, а не диагноз — а самая дорогая ошибка автовладельца это оплатить честную цену за замену исправной детали.

Не знает, что именно поставили: оригинал законно дороже аналога в 2–3 раза.

Не заменяет заключение эксперта.

## Статус

Прототип. Справочник нормативов собран из открытых источников, часть цифр оценочная — это помечено прямо в интерфейсе.
